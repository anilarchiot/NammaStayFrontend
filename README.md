# NammaStay — hostel app (https://app.thenammastay.com)

The app hostel owners and staff use: sign-in, sign-up, dashboard, bookings, calendar, check-in, Form C, rooms,
OTA sync, payments, reports, expenses, settings, and the guest's online check-in page (`self-check-in.html`).

- Hosted on GitHub Pages from this repo, custom domain **app.thenammastay.com** (the `CNAME` file).
- `assets/js/config.js`: paste the Supabase Project URL + anon key (same project as the homepage and admin site).
- The homepage lives in its own repo (thenammastay.com); the admin website in another (admin.thenammastay.com).
